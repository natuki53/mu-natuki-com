# mu-natuki-com

自作サーバーに載せる用の **自己紹介/ポートフォリオページ** です。  
Vite（Vanilla JS）でビルドして、生成された静的ファイルをサーバーに配置して運用します。

## 開発環境

- Node.js（Viteが動くバージョン）
- npm

## ビルド / プレビュー

```bash
# 本番用ビルド（dist/ が生成されます）
npm run build

# ビルド結果をローカルで確認
npm run preview
```

## ローカル起動

表示されたローカルURL（例: `http://localhost:5173`）にアクセスします。
